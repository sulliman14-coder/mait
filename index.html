```
سيُملأ تلقائياً حسب المزود — يمكنك تغييره
🧠 المُحوّل الذكي (Smart Adapter)
عند الاتصال، يكتشف النظام تلقائياً نوع البروتوكول (OpenAI-compatible / Anthropic / Gemini)، يضبط الرؤوس والمفاتيح الصحيحة، ويتعامل مع أخطاء (401 مفتاح خاطئ / 429 حد الاستخدام / CORS / مهلة) ويعيد المحاولة بذكاء.
```

📋 خطوات التشغيل الكاملة
1

اختر واربط مزود الذكاء الاصطناعي

اذهب لـ الإعدادات ← مزود الذكاء الاصطناعي. اختر أي مزود تملك مفتاحه (OpenAI أو Claude أو Gemini أو Groq أو DeepSeek أو OpenRouter أو مخصص). ألصق المفتاح واضغط حفظ واختبار. النظام سيكتشف البروتوكول الصحيح تلقائياً.

2

من أين أحصل على مفتاح API؟

OpenAI: platform.openai.com/api-keys · Claude: console.anthropic.com · Gemini: aistudio.google.com/apikey · Groq (مجاني): console.groq.com · OpenRouter: openrouter.ai/keys · DeepSeek: platform.deepseek.com

3

ابحث عن العملاء

اذهب لـ بحث ذكي متقدم ← اختر مجال عملك ← اختر القطاعات المستهدفة (جزئياً أو كلياً) ← اضبط الخيارات ← فعّل الاستيراد التلقائي إن رغبت ← اضغط بحث. ستظهر الشركات ببياناتها وروابطها.

4

انشر الخادم الخلفي (للإرسال الفعلي)

انسخ كود الخادم أدناه ← ارفعه على GitHub ← انشره مجاناً على Render.com أو Railway.app: New → Web Service → اربط المستودع → Build: npm install → Start: npm start → أضف متغيرات البيئة → انشر. خذ الرابط وضعه في الإعدادات.

5

فعّل كلمة مرور تطبيق Gmail

حساب Google → الأمان → فعّل التحقق بخطوتين → كلمات مرور التطبيقات → أنشئ كلمة (16 حرف) → ضعها في متغير SMTP_PASS بالخادم.

6

ابدأ الحملات

اختر العملاء ← الحملات ← اختر بريد أو واتساب ← اضبط الحماية ← نفّذ. سيولّد رسالة مخصصة لكل شركة، يتتبع الفتح، ويعيد الإرسال تلقائياً لمن لم يفتح.

7

تابع وحلّل

من التحليلات راقب معدلات الفتح والرد، ومن الوارد رد على العملاء، ومن الجدولة اضبط سلسلة المتابعة التلقائية.

8

حل المشكلات الشائعة

401: مفتاح خاطئ، أعد نسخه. 429: تجاوزت الحد، انتظر أو بدّل المزود. CORS: بعض المزودات تمنع الاستدعاء من المتصفح — استخدم خادمك كوسيط (الكود يدعمه عبر /api/ai). مهلة: النظام يعيد المحاولة تلقائياً مرتين.
