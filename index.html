📋 خطوات التشغيل
1

احصل على مفتاح Anthropic

سجّل في console.anthropic.com → API Keys → Create Key → انسخه والصقه في الإعدادات. هذا وحده يكفي لتشغيل البحث والكتابة بالذكاء.

2

انشر الخادم الخلفي (للإرسال الفعلي)

انسخ كود الخادم أدناه، ارفعه على GitHub، ثم انشره مجاناً على Render.com أو Railway.app. خذ الرابط وضعه في الإعدادات.

3

فعّل كلمة مرور تطبيق Gmail

حساب Google → الأمان → التحقق بخطوتين → كلمات مرور التطبيقات → أنشئ واحدة وضعها في متغيرات بيئة الخادم.

4

ابدأ الحملات

ابحث عن العملاء → ولّد الرسائل → نفّذ الحملة. سيتتبع النظام الفتح ويعيد الإرسال تلقائياً.
