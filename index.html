🎯 الخطوة 1: احصل على مفتاح AI
1

اختر المزود المجاني (يكفي واحد منهم)

Groq (الأسرع المجاني): اذهب إلى console.groq.com → سجّل دخول بـ Google → API Keys → Create API Key → انسخ المفتاح الذي يبدأ بـ gsk_

OpenRouter (الأكثر نماذج): اذهب إلى openrouter.ai → Sign up → Keys → Create Key → انسخ المفتاح الذي يبدأ بـ sk-or-

Gemini (Google): اذهب إلى aistudio.google.com → Get API Key → انسخ المفتاح الذي يبدأ بـ AIza

⚙️ الخطوة 2: ربط المفاتيح
2

أدخل المفاتيح في الإعدادات

  • اذهب لتبويب الإعدادات ⚙️
  • الصق المفتاح في خانة المزود المناسب
  • اضغط 🔌 اختبار — ستظهر علامة ✅ خضراء عند النجاح
  • اضغط ⭐ بجانب مزودك المفضل ليصبح هو الافتراضي للتنقيب
  • اضغط 💾 حفظ كل الإعدادات

💡 يمكنك ربط عدة مزودين معاً — النظام يستخدم الأسرع ويعود للبقية تلقائياً إذا فشل أحدهم.

🔍 الخطوة 3: استخدام التنقيب الذكي
3

التنقيب العميق عن العملاء المحتملين

  • اذهب لتبويب 🔍 التنقيب الذكي
  • اختر محرك التنقيب من الشريط العلوي (المفضل ⭐ مُحدد افتراضياً، لكن يمكنك تبديله يدوياً)
  • اختر القطاع المستهدف والمدينة
  • حدد الفترة الزمنية (اليوم/أسبوع/شهر/6 أشهر) — كلما كانت أقرب كانت الإشارات أحدث وأقوى
  • اختر التنقيب العميق للحصول على إشارات نية حقيقية (مشاريع، توسعات، مناقصات) — وليس مجرد قائمة شركات معروفة
  • اضغط 🚀 ابدأ التنقيب العميق
  • ستظهر النتائج مع: اسم الشركة + سبب الاهتمام + بيانات التواصل + الموقع + LinkedIn + مصدر الإشارة

🔬 الفرق بين التنقيب العميق والقياسي:
- القياسي: قائمة شركات مشهورة في القطاع
- العميق: شركات أعلنت مؤخراً عن مشاريع/توسعات/مناقصات تحتاج خدماتك

✍️ الخطوة 4: كتابة وإرسال الرسائل
4

كيف ترسل رسائل احترافية

  • من النتائج: حدد العملاء بالـ checkbox أو اضغط ✍️ بجانب أي عميل
  • اذهب لتبويب ✍️ كتابة الرسائل
  • اختر العميل من القائمة المنسدلة (أو أدخل بياناته يدوياً)
  • اختر نوع الرسالة (تعريفية / متابعة / عرض)
  • اضغط 🤖 توليد الرسالة — سيكتب AI رسالة مخصصة بالكامل
  • راجع وعدّل إن احتجت (زر ✏️ تعديل)
  • للإرسال: 📧 بريد (يحتاج خادم) أو 📱 واتساب (مباشر)
📱 الخطوة 5: واتساب — طريقة العمل
5

كيف يعمل واتساب في النظام

عند الضغط على 📱 واتساب يفتح النظام نافذة اختيار:

  • واتساب ويب: يفتح في تبويب جديد، اختر web.whatsapp.com إذا كنت تستخدم اللابتوب
  • واتساب الموبايل: يفتح تطبيق واتساب مباشرة على هاتفك
  • الرسالة ستكون جاهزة ومخصصة — تحتاج فقط الضغط على زر الإرسال

⚠️ مهم: تأكد من السماح للنوافذ المنبثقة (Pop-ups) في إعدادات المتصفح لهذا الموقع — وإلا قد لا يفتح واتساب.

🚀 الخطوة 6: الحملات الجماعية
6

إرسال جماعي ذكي مع حماية

  • اذهب لتبويب 🚀 الحملات
  • اختر نوع الحملة (بريد أو واتساب)
  • اضبط التأخير بين الرسائل (30-90 ثانية موصى به لتجنب الحظر)
  • اضغط 🚀 تنفيذ الحملة
  • سيُنتج AI رسالة فريدة لكل شركة + يرسلها مع تأخير عشوائي
🖥️ الخطوة 7: (متقدم) الخادم الخلفي
7

للإرسال الفعلي للبريد وتتبع الفتح

الواجهة وحدها لا ترسل بريد فعلي — تحتاج خادم بسيط. الخطوات:

  • أنشئ كلمة مرور تطبيق في Gmail: حسابك → الأمان → التحقق بخطوتين → كلمات مرور التطبيقات
  • انسخ كود الخادم أدناه إلى ملف server.js
  • أنشئ package.json من الكود أدناه
  • أنشئ .env وضع فيه بياناتك
  • ارفع المشروع على GitHub
  • اذهب إلى render.com → New Web Service → اربط GitHub → Deploy
  • انسخ رابط الخادم من Render وضعه في الإعدادات
🖥️ كود الخادم (server.js)
📦 ملف package.json
🔐 ملف .env
🌐 نشر الواجهة (المتصفح)
📤

على Vercel / Netlify (مجاناً)

  • Netlify: اسحب وأفلت مجلد الموقع كاملاً (يحوي index.html + app.js) في netlify.com → سيعمل فوراً
  • Vercel: ارفع الملفات على GitHub → اربط المستودع بـ Vercel → اختر "Other" framework → Deploy
  • GitHub Pages: ارفع الملفات على Repository → Settings → Pages → Branch: main → Save

✅ كل مفاتيح API تُحفظ في متصفحك (localStorage) — لن تُرفع لأي خادم.
